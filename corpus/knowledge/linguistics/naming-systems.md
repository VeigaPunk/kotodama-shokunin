## 1. The frame: four name systems plus one force

- Onomastics splits by what is named: **anthroponymy** (persons), **toponymy** (places), **theonymy** (gods), and the transit layer between polities and languages (**endonym/exonym**). The fifth element is not a system but a force: **name taboo and name magic** — the doctrine that the name is the thing named — which bends all four. A culture's kotodama is a theory of reference with institutional consequences (registers, forbidden characters, erasure rites), not decorative flavor.
- Alford (1988), surveying a probability sample of the Human Relations Area Files: personal names are universal; the toolkit is small and recombines — given names, alternate names, teknonymy, namesake inheritance, post-mortem avoidance. Systems differ mainly in **how many names a person holds, who assigns them, and when they change**, not in whether they exist.
- Working rule: every name in the ledger records three things — a **claim** (who may say it, when, in which language), a **fossil** (of an older language, regime, or taboo), and a **spell** (what in-world happens if it is said).

## 2. Anthroponymy: the slot system

- Slots: **given** (personal), **lineage link** (patronymic/matronymic), **clan/house name** (hereditary), **byname** (descriptive, often later hereditary), plus **life-stage**, **office**, and **posthumous** names. Which slots exist is a society-type signal: segmentary lineages run patronymic chains; centralized bureaucracies run fixed hereditary surnames + generation names; small-scale societies run relational names — **teknonymy** (a parent is renamed after the child, Bali: Geertz & Geertz 1964).
- Comparative mechanics:

| System | Slots and behavior | Design lever |
|---|---|---|
| Icelandic | given + patronymic -son/-dóttir; no hereditary surname; state committee vetoes unfit given names (Mannanafnanefnd, 1991; current Names Act 1996 — to-verify) | a name bureaucracy with no surname to hide behind |
| Roman | tria nomina: praenomen + nomen (gens) + cognomen; cognomen hereditary by late Republic (Kajanto 1963) | slots fossilize in order of institutional need |
| Arabic | given + nasab chain (ibn/bint + father), kunya (Abū + child), nisba (origin/trade), laqab (honorific byname) | a chain recomputed every generation — genealogy as memory |
| Chinese | surname first + given + generation-pool character; hereditary surname ~ancient; emperor's personal name banned in print (see §6) | generation names make a poem-walk through a genealogy |
| Japanese (classical) | multiple simultaneous names: childhood yōmyō, adult imina (avoided in address), azana courtesy name, gō pen name, okurina posthumous (inventory: O'Neill 1972) | one person, five names, each owned by a different relation |
| Russian | given + patronymic -ovich/-evna + hereditary surname; short/diminutive forms grade intimacy; bare given name without patronymic is the insult form (Unbegaun 1972) | address morphology is a status dial (couples sociolinguistics-registers) |
| Balinese | birth-order name + teknonymy + status titles (Geertz & Geertz 1964) | genealogical amnesia: depth replaced by relational position |
| Inuit | name inheritance of the dead; the child *is* the namesake (saunik/sauniq "bone" bond); post-mortem taboo of the deceased's name until passed (Guemple 1965; Alia 2006) | names are reincarnation machinery, and grief is grammatical |

- Formation rules: connectors (Gaelic mac-/nic-, Norman fitz-, Arabic ibn/bint, Slavic -ovich/-evna, Scandinavian -son/-dóttir, Armenian -yan, Georgian -shvili); **dithematic** Germanic names built from two roots of the name lexicon (Theodoric "people-ruler"; evidence: Förstemann) vs **monothematic** pools; saint/god-derived given names track conversion eras.
- The **name lexicon** is a distinct semantic field: archaic, sacred, or legally curated roots that ordinary speech has lost (couples semantic-fields-lexicon-building). Japan still legally restricts which characters may be used in given names (Jōyō + jinmeiyō kanji lists under the Family Register system; list dates/size to-verify) — a state-curated name lexicon in the present tense.
- English surname types (Reaney & Wilson 1991): local (place), occupational, nickname, baptismal — four strata of one society's career, read from the rolls.
- Surnames are usually *mandated by the state* — era markers, not universals: Habsburg patent 1787 (Joseph II, fixed surnames for Jewish subjects); Meiji edicts 1870/1875 (commoners required); Sweden's Names Adoption Act Dec. 1901; Norway 1923; Turkey's Soyadı Kanunu 1934 (which renamed Mustafa Kemal into Atatürk). Iceland to date: no hereditary surname requirement. A world's "old families" are just early adopters of a bureaucratic event.

## 3. Toponymy: functions, strata, politics

- Functional types (standard typology, cf. Kadmon 2000; narrative: Stewart 1945): **descriptive** (Black Forest, Table Mountain), **associative** (a town named for its river), **commemorative/eponymous** (Alexandria; MLK boulevards — Alderman 2000), **commendatory** (Greenland — Eiríks saga rauða reports Erik chose the green name to attract settlers; generic propaganda names: Hope, Prosperity), **transfer/shift** (New York from York; New Amsterdam renamed New York on capture), **folk-etymologized** (opaque reshaped to familiar words).
- Place names **stratify**: each conquest or migration overlays the previous language, and old morphemes fossilize as opaque heads. Classic English data (Gelling 1978; Cameron 1996): Celtic + Old English + Norse + Norman layers; **tautologies** betray the strata — Bredon (Worcs.) is attested from 772 as Breodune, Celtic *bre* "hill" + *dun* "hill/down", "hill-hill", and Breedon-on-the-Hill (Leics.) is "hill-hill hill" (Duignan 1905).
- **Folk etymology** (Hock 1986): an opaque name is regularized to a famous word (real and in-world). Live lever: let in-world guides "explain" place names wrongly and confidently — folk etymology is how commoners do philology.
- **Critical toponymy** (Rose-Redwood, Alderman & Azaryahu 2010): naming is inscription of power; the street grid is a city-text. Regime changes rewrite it: Leningrad→Petrograd→Leningrad→St Petersburg; Bombay→Mumbai (1995); Salisbury→Harare; Shanghai's roads renamed wholesale after 1949 (documented case study in Urban History). Every renaming is datable; a map is an archive of coups.
- Standardization layer: UNGEGN (UN Group of Experts on Geographical Names) runs the endonym-first principle — maps should show the name locals use (UNGEGN 2002). Pinyin (PRC, 1958; endorsed by the UN for Chinese names, 1977) is the textbook case of romanization as geopolitical act. For this corpus, stabilize language names with Glottolog glottocodes, ISO 639, BCP 47 (couples writing-systems).

## 4. Theonymy: names of gods

- **Transparent vs opaque** theonyms (Versnel 2011): some divine names still *mean* their function (Vedic Agni = fire), most are opaque fossils of older languages. Design both: young gods transparent, old gods opaque — the opacity gradient *is* your mythic chronology (couples myth-symbol).
- The PIE chain is the working demo: *Dyēus ph₂tēr "Sky Father" → Zeus (pater), Jupiter (Diu-piter), Vedic Dyaus pitár (Mallory & Adams 2006; Watkins 1995). One reconstructible name, three nationalized gods: cognate theonyms are a comparative-linguistics dowry.
- **Cult epithets** (Burkert 1985): Greek practice splits one god into many cult persons by theonym + epithet — Athena Polias "of the city", Athena Nike; Zeus Soter, Zeus Kataibates "who strikes down". Epithets are mostly toponyms and functions: gods stick to places. Build the toponymy first; the epithet inventory falls out of it.
- **Syncretic mapping**: interpretatio romana (Tacitus, Germania 43) — a conquering culture publishes a lookup table from foreign god to native god. In-world, the mapping is a political instrument: it decides which gods are "the same" and which heresies that implies.

## 5. Endonym/exonym: the transit layer

- Definitions (UNGEGN 2002): **endonym** = the name insiders use; **exonym** = an established outside name. Aurousseau (1957) coined "exonym"; "endonym" was coined later as its counterpart.
- One country, four roots — Germany: Deutschland ("of the people"), Germany (Latin Germani, a tribe, origin uncertain), Allemagne (the Alemanni), Niemcy/Saksa (Slavic "the mutes", standard etymology from *němъ; Finnish from the Saxons). Each root is a different contact event frozen in another language's mouth.
- Route layering: names travel trade routes and each carrier adds its phonology — Sanskrit Cīna (origin debated; the Qin dynasty is one candidate, not settled) → China; the Khitan steppe state → Cathay (hence Russian Kitay); Chinese 日本國 "sun-origin" via Marco Polo's Cipangu → Malay Japang → Japan. Marco Polo reported China and Cathay as *different countries* — one endonym can arrive twice and look like two places.
- Craft rules: (1) exonyms are period evidence — who called whom what dates the contact; (2) pejorative exonyms ("mutes") are slur fossils and can be reclaimed or shed by renaming movements; (3) a state that renames itself (endonymic assertiveness) is announcing a regime (couples era files).

## 6. Name taboo and name magic: the kotodama core

- The premise: the name is the essence; to know it is to grasp, to say it is to command or summon, to erase it is to kill. This is not marginal folklore — entire bureaucracies run on it.
- Institutional data, by mechanism:

| Culture | Mechanism | Consequence you can port |
|---|---|---|
| China (bìhuì 避讳) | the emperor's personal-name characters vanish from print: substitution, missing strokes, renamed offices/posts (Wilkinson 2018) | documents are **datable by which characters are missing** — a taboo calendar |
| China (exam case) | Li He barred from the jinshi exam because his father's name Jin-su 晋肃 homophones 进士; Han Yu's essay Hui bian 讳辩 (c. 803) attacks the rule | homophonic taboo as a weapon in career politics |
| China (family) | Sima Qian avoids his father Tan's name 谈 in the Shiji (standard example; specific rewritten name to-verify) | descendants' names censor archives — filial piety as redaction |
| Korea (Joseon) | royal personal name (pyehui) avoided; characters avoided in print and even place names (specific renamings to-verify) | ruler-name taboo as dynasty-spanning typography |
| Japan | adult name (imina) not used in address — office, byname, or courtesy name instead (azana, gō); emperors get posthumous names (okurina) (inventory: O'Neill 1972) | the "real name" is held in trust, spoken at enfeoffment and death only |
| Egypt | the name (rn) is a body-part; chiseling out Hatshepsut's and Akhenaten's cartouches = second death (Assmann 2005; mnemohistory: Assmann 1997) | erasure as capital punishment for memory |
| Rome | damnatio memoriae: name and face systematically abolished (Varner 2004) | the erased leave chiseled ghosts — great scenery, real archaeology |
| Hebrew | the Tetragrammaton unpronounced: Adonai in liturgy, HaShem outside it; Kabbalah theorizes the Name as creation's syntax (Scholem 1972) | a name-register split by occasion (couples sociolinguistics-registers) |
| Inuit | deceased's name tabooed until a newborn inherits it; namesake and named are one person (Guemple 1965; 1979) | grief management by grammar; the dead keep talking |
| Dyirbal | mother-in-law register Jalnguy replaces everyday words in presence of taboo kin (Dixon 1972) | kin taboo can split the whole lexicon in two |

- Kotodama proper (言霊, "word-spirit"): the belief that spoken words carry spirit-power to bless, curse, and actualize. Primary attestation: Hitomaro in the Man'yōshū — Yamato praised as *kotodama no tasuku fuku kuni* / *sakiwau kuni*, "the land the word-spirit blesses" (MYS 3253–3254); related is *kotoage* 言挙げ, "raising words" — declarative speech that makes things so (attested in the norito liturgy; scope to-verify). The label "kotodama faith" (*kotodama shinkō*) as a coherent ancient doctrine is a modern scholarly reconstruction — standardly attributed to Orikuchi Shinobu (1920s–30s) — and was weaponized in wartime language ideology; Miller (1982) is the standard critique (see §8).
- Folklore mechanics (the portable rules): **ATU 500** — guessing the supernatural being's true name breaks its hold (Rumpelstiltskin; Uther 2004); **Odyssey 9** — Odysseus gives the Cyclops the false name Outis "Nobody" and escapes the curse addressed to Nobody. Three canonical moves: true name = power over; false name = immunity; renaming = rebirth/sanctuary (novice, enslaved, married, dead all get new names).
- Design consequences: why servants never say the lord's name; why archives have character-shaped holes; why a dynasty's typographers date it; why pseudonyms are polite, not criminal; why an erasure trial is scarier than an execution.

## 7. Derivation pipeline: naming a fictional culture

1. **Phonology filter** — a legal name is a well-formed string of the culture's language (couples phonetics-phonology). Allow a divergent *name lexicon* with archaic phonemes; fossil phonemes in names date your strata (couples historical-linguistics).
2. **Slot inventory & order** — choose given/lineage/clan/byname slots, their order (given-first vs family-first is a real cross-cultural split), and which slots are grammaticalized (affixed patronymics vs free chains).
3. **Formation rules** — dithematic vs monothematic pools; connector morphology (mac-/ibn/-ovich/-dóttir); decide if names can sound like ordinary words (they usually may not).
4. **Lexify** — draw name roots from a curated semantic field (occupations, virtues, saints/gods, plants, weapons, generation-pool characters); record the pool in the lexicon file (couples semantic-fields-lexicon-building).
5. **Taboo layer** — decide what is avoided when: post-mortem, ruler-name, in-law, sacred-name, homophone taboos; each taboo generates a mechanism (substitution, missing strokes, office-names) and a stratum (see §6 table).
6. **Life-stage schedule** — how many names does one person hold at birth, majority, office, marriage, death? Who may speak which one, and who assigns them? This table is where scenes live.
7. **Exonym layer** — for each neighbor, derive their name for this culture along a plausible route (trade, conquest, missionary); add at least one pejorative root and one double-arrival case (§5).
8. **Toponym layer** — stratify the map: substrate names + each regime's commendatory/commemorative layer; place one tautology and one folk-etymology on purpose (§3).
9. **Theonym layer** — old gods opaque, young gods transparent; derive cult epithets from the toponyms; write the conquering culture's syncretic mapping table (§4).
10. **Ledger + stress tests** — keep a name ledger (etymology, stratum, taboo status, who may say it). Stress-test: a coronation (which name is spoken?), a funeral (which name is erased?), a market between two exonym-using peoples, a court clerk dating a document by its missing characters.

Worked micro-example: a mountain-republic with Norse-style patronymics, an imperial homophone taboo on the usurper dynasty's founder's name (its character vanishes from all legal print — coinage for "engraver's stroke"), two rival exonyms ("ridge-mutes", "goat-eaters") from the two trade routes, and a summit named hill-hill-hill from three dead languages. The republic's philologists date every surviving charter by which taboo-run each avoids.

## 8. Calibration: contested, discredited, commonly botched

- **Dumézil's trifunctional ideology**: influential but contested as method — classic critiques from Brough (1959), Thieme (1957), Gonda (1976); Belier (1991) dissects the evidence base. Use trifunctionalism as an in-world theology a sage might propose, not as reconstructible fact. The *Dyēus ph₂tēr* cognate set itself is solid; the social-ideology superstructure is not.
- **Kotodama as timeless national essence**: discredited as history. The coherent doctrine is a modern construction (Orikuchi), amplified by 1930s–40s nationalism and postwar nihonjinron (Miller 1982). What is attested: the Man'yōshū formulas, kotoage in liturgy, and name-avoidance practice. Port kotodama as an *in-world theory of reference* with institutions, not as a real magic constant — unless the world bible decides magic is real (that decision is lore-shokunin's).
- **Clan tartans and costume-name packages**: the per-clan tartan system is largely a 19th-century commercial invention; the *Vestiarium Scoticum* (1842) is a forgery (Trevor-Roper 1983 in Hobsbawm & Ranger). When coupling naming to costume, inventing an "ancient" insignia system in-world is period-plausible — just mark the forgery as a plot affordance, not as deep time.
- **Famous name trivia is often fake**: "Torpenhow Hill" (four hills) is a phantom — the village Torpenhow is attested (12th-c. Torpenhou), but no landform bears the quadruple name (Mills; Francis's analysis). Verify every viral tautology before putting it in canon; tautologies like Bredon are real, ghost names travel faster.
- **Acronym surname etymologies** ("Porters cross: P-O-R-T-E-R") are virtually all false — acronymy is a folk-etymology attractor. Also distrust tidy "surname X means 'son of the wolf'" dictionaries; single-gloss etymologies of ethnonyms and surnames are frequently speculative.
- **Frazer-style universal name-magic**: the comparative ethnography is discredited (see politeness-taboo-euphemism §7); the *practices* (name avoidance, renaming, erasure) are individually well-attested as above. Build institutions from the documented cases, not from "all primitives believe".
- **Strong Whorf/kotodama determinism** ("language shapes reality" as fact): no scientific support; run it as in-world ideology, with believers and skeptics.
