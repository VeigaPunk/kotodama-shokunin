## Family ownership — an engine name is not a culture source

A shared projector can provide parsing and routing mechanics without supplying a
culture's records. Determine the input family from its own declared assembly and
source map. In a family's owned label fields, the form, owner, representation
scheme, and source-record citation must resolve to that family's packet or
components. Reusing the D2 engine never licenses inserting D2's rank law, materials,
institutions, or record citations into a D4-owned projection.

| Condition | Required behavior | Never | Control |
|---|---|---|---|
| A non-D2 packet uses the shared typed-label engine | Project its own label fields and rank records; retain the shared implementation/design citations as method references, not fictional evidence | Select the embedded D2 rank fixture merely because the implementation file is named `d2-typed-labels.py` | The filed pre-fix D4 projection must fail a family-source scan that the corrected D4 projection passes; the canonical D2 projection remains byte-identical |
| A family-local rule cannot be represented by the shared normalizer | State the unimplemented or held leg and its owner; do not fabricate a normalization or count a skipped leg as checked | Substitute another family's rules to obtain a populated ledger or a green result | Compare projected coverage with the input family's declared records and exercise the absent/unsupported-leg case |
| A family's brief forbids importing another fixture's system | Remove the foreign fixture records from that family's projection; preserve only legitimate shared method references and the packet's own linguistic borrow ledgers | Rename the D2 fixture block as borrowed to evade D4's no-import boundary; confuse a declared linguistic loan with permission to borrow a fixture | D4 rank coverage is exactly its four RK rules; D2-constant poison leaves D4 unchanged while a local RK mutation changes its corresponding D4 projection |
| Removing fixture contamination changes a finding set | Explain each removed or retained row by independent design/source evidence, then issue new frozen rows and carry the open native-form obligations forward | Copy the producer's new stdout into an expectation and call the smaller set a clearance; rewrite a filed baseline | A planted native-form obligation still produces its hold; the old snapshot and its recorded finding set remain unchanged |
| A fixed source moves a projection or profile pin | Regenerate from the canonical packet path; re-pin live resolution fields and create new frozen generations with command, date, input/tool hashes, and replay results | Re-bless a historical baseline in place, or freeze while an upstream source is still changing | Stale pins refuse; tampered frozen input fails before replay; a clean snapshot replays the exact observed verdict |

Thresholds and cautions that are part of the rule:

- **T1 — scope by ownership, not by a global substring ban.** A reference to a
  shared engine or historical method document is not a D2 fictional record.
  Conversely, a foreign fixture compiled into an engine is still foreign data
  even if the build never opens an `examples/culture-d2` file.
- **T2 — equality and isolation are independent.** Before this repair the
  canonical D4 gate passed 19/19 and the adapter passed 12/12 while the D4
  projection carried D2's 21-record rank fixture. A deterministic projection
  can deterministically reproduce the wrong family.
- **T3 — obligations survive a data-cleanup.** The six garment-form obligations
  remain open; the projection may name each as both a garment row and its owed
  slot row. Removing foreign rank residuals must not remove either side of the
  legitimate routing/hold equality.
- **T4 — new pins record a new revision.** Preservation of filed rounds and
  negative controls are separate evidence from a green new row. A replay that
  reads live peer files also needs their digest verification; the generic TSV
  gate/input/output pins alone do not bind every peer.
- A source-isolation pass is not a historical or linguistic truth finding, a
  real-world permission ruling, lore acceptance, or canon. Handoffs remain
  prepared-not-accepted until the receiving lane supplies its own acceptance.
