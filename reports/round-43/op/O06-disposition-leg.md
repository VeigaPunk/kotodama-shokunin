## 3. Artifact contract

### 3.1 Name and location (binding)

```
reports/round-43/calib/couples-census-r43.json
```

- **One artifact, one name.** O10 must use this exact path; do not file a second
  census under `op/`. The r42 stdout-capture precedent
  (`reports/round-42/op/couples-extractor-census.json`) is superseded by this
  structured artifact for round 43.
- `--census` writes this path by default. `--out PATH` overrides; `--stdout`
  prints the same JSON and writes nothing. A scoped run (`--census PATH...`) may
  **not** overwrite the canonical full-corpus artifact unless `--out` is given.
- **Generate it after the C01 lithic entry is applied.** The claim's census is
  the post-landing state (224 entries); a pre-landing run records
  `corpus.entries: 223` and cannot satisfy the claim. `corpus.baseline_commit`
  may still be `7ceff59` for a pre-commit run; `corpus.corpus_fingerprint` pins
  the actual tree, and `corpus.state_note` records
  `"post-C01-landing, pre-commit"` (CLI `--note TEXT`).
- Write the canonical file **only if all invariants pass** (§5). On failure write
  `<name>.failed.json`, print the errors, exit 1. Never let a failed run leave a
  file that looks filed.

## 4. Closed vocabularies

### 4.1 Reason codes and their class

| reason_code | class | meaning |
|---|---|---|
| `direct-entry-dir` | direct | Tier 1 hit at `<entry dir>/<token>` |
| `direct-lane-root` | direct | Tier 1 hit at `<lane root>/<token>` |
| `direct-knowledge-root` | direct | Tier 1 hit at `corpus/knowledge/<token>` |
| `unique-basename` | fallback | Tier 2: exactly one `corpus/knowledge/*/*.md` basename match |
| `duplicate-basename` | ambiguous | Tier 2: ≥2 basename matches; §2(c) requires exactly one |
| `slash-path-not-found` | unresolved | Tier 1 failed; token is slash-bearing, §5.1 forbids the fallback |
| `dangling-basename` | unresolved | Tier 1 failed; zero basename matches |
| `declared-prospective-seed` | prospective | field declares a prospective seed (`prospective sibling files:` / `files to seed` / `sibling knowledge files to seed`) |
| `glob-pattern-artifact` | glob-fragment | token derived from a `*` glob in the field; policy §5.6 |
| `unreadable-entry` / `unknown` | any | tool could not read/classify; **must** produce `could-not-classify` |

The reason codes are structural. Semantic dispositions ("phantom", "typo") are
**not** reason codes — they belong to the routed row's `reason`/`near_miss`, so
the tool never guesses intent.

### 4.2 Disposition, blocker, owner, and the evidence each row owes

| class | condition | disposition | blocker | owner | required evidence |
|---|---|---|---|---|---|
| direct | Tier 1 hit | `resolved-direct` | false | `null` | `resolution.basis` + `mapping` |
| fallback | unique hit, alignment `ok`/`not-applicable` | `resolved-fallback` | false | `null` | non-null `resolution.mapping` |
| fallback | unique hit, alignment `MISALIGNED` | `alignment-finding` | true | `integrator` | mapping **and** the mismatching group (§4 policy: finding, not resolution) |
| ambiguous | ≥2 hits | `blocker-ambiguous` | true | `integrator` | `resolution.candidates` with every hit |
| unresolved | slash-bearing + `near_miss` | `route-corpus-fix` | true | `integrator` | `near_miss` + carrier line |
| unresolved | dangling + `(to-verify` on the token's part | `documented-non-blocker` | false | `corpus-owner` | `documented_locator` |
| unresolved | dangling, no marker | `blocker-dangling` | true | `corpus-owner` | reason + carrier line |
| prospective | declared seed | `declared-prospective-seed` | false | `corpus-owner` | declaration marker + line |
| glob-fragment | glob artifact | `extractor-artifact-excluded` | false | `null` | `source_span` |
| any | unreadable/unknown | `could-not-classify` | true | `integrator` | the error text; exit non-zero |

Disposition is a function of class + evidence, **not** a hand assignment. The
tool asserts the table; a mismatch is an invariant error (§5 I10).

## 5. Reconciliation invariants (the "never dropped" proof)

The artifact is admissible only if all hold; otherwise `.failed.json` + exit 1.

- **I1** `corpus.entries == len(entries)`.
- **I2** `totals.refs == sum(len(e.tokens))`.
- **I3** per entry: `e.expanded_refs - e.dedup_repeats == len(e.tokens)` and
  `sum(e.counts.values()) == len(e.tokens)`.
- **I4** `sum(e.expanded_refs) == reconciliation.expanded_refs` and
  `sum(e.expanded_refs) == totals.refs + reconciliation.dedup_repeats`.
- **I5** every `fallback` row: `resolution.mapping` non-null, `os.path.isfile`,
  `index_hits == 1`; mapping is listed in `fallback_mappings`.
- **I6** every `ambiguous` row: `len(candidates) >= 2`, every candidate exists;
  no `mapping`.
- **I7** every `unresolved` row: `reason_code` ∈ {`slash-path-not-found`,
  `dangling-basename`}, non-empty `reason`, `disposition` ∈
  {`blocker-dangling`, `documented-non-blocker`, `route-corpus-fix`}, `owner`
  non-null.
- **I8** every `blocker: true` row has a non-null `owner`.
- **I9** `totals.refs == sum(policy_four) + sum(aux)`; the four policy classes are
  never merged with the aux classes (§3.2 of the policy: fallback is never merged
  into direct; the same logic keeps prospective/glob-fragment out of
  resolved/unresolved).
- **I10** `disposition_counts` sums to `totals.refs`, and each row's
  `disposition` matches §4.2 for its `(class, evidence)` pair.
- **I11** `reconciliation.unaccounted == 0` and
  `reconciliation.invariant_errors == []`.

Aux classes are reported, not hidden: a "zero unresolved" line that omits the
5 prospective seeds and the 1 glob fragment would drop 6 real tokens from the
accounting. The four policy classes stay primary; the aux lines sit beside them.

## 7. Fenced draft (liftable reference, not the tool)

### 7.1 Disposition function

```python
# --- draft: O06 disposition leg (host: tools/harness/basename-couples-resolver.py)
CLASSES = ("direct", "fallback", "ambiguous", "unresolved", "prospective", "glob-fragment")
REASONS = {
    "direct": ("direct-entry-dir", "direct-lane-root", "direct-knowledge-root"),
    "fallback": ("unique-basename",),
    "ambiguous": ("duplicate-basename",),
    "unresolved": ("slash-path-not-found", "dangling-basename"),
    "prospective": ("declared-prospective-seed",),
    "glob-fragment": ("glob-pattern-artifact",),
}

def disposition_for(cls, reason_code, alignment, documented, near_miss):
    """Return (disposition, blocker, owner). Closed table, never a guess."""
    if cls == "direct":
        return "resolved-direct", False, None
    if cls == "fallback":
        if alignment == "MISALIGNED":
            return "alignment-finding", True, "integrator"
        return "resolved-fallback", False, None
    if cls == "ambiguous":
        return "blocker-ambiguous", True, "integrator"
    if cls == "prospective":
        return "declared-prospective-seed", False, "corpus-owner"
    if cls == "glob-fragment":
        return "extractor-artifact-excluded", False, None
    if cls == "unresolved":
        if documented:
            return "documented-non-blocker", False, "corpus-owner"
        if reason_code == "slash-path-not-found" and near_miss:
            return "route-corpus-fix", True, "integrator"
        return "blocker-dangling", True, "corpus-owner"
    return "could-not-classify", True, "integrator"
```

### 7.2 Row builder (the shape, with the live wrapped-field case)

```python
def token_row(row_id, token, cls, reason_code, reason, resolution, group,
              alignment, disposition, blocker, owner, occurrences, line_span,
              anchors=None, expanded_from=None, near_miss=None,
              documented=None, documented_locator=None, source_span=None):
    row = {
        "row_id": row_id,
        "token": token,
        "class": cls,
        "reason_code": reason_code,
        "reason": reason,
        "resolution": resolution,          # tier/basis/mapping/index_hits[/candidates]
        "group": group,
        "alignment": alignment,            # ok|MISALIGNED|not-applicable|null
        "disposition": disposition,
        "blocker": blocker,
        "owner": owner,
        "occurrences": occurrences,
        "line_span": line_span,
    }
    if anchors: row["anchors"] = anchors
    if expanded_from: row["expanded_from"] = expanded_from
    if near_miss: row["near_miss"] = near_miss
    if documented is not None: row["documented"] = documented
    if documented_locator: row["documented_locator"] = documented_locator
    if source_span: row["source_span"] = source_span
    return row
```
