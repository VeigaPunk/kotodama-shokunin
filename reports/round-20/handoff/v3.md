## 1. What v3 is

The third generation of the handoff-e2e exercise, delivered as **three profiles
on one tool** (design §6):

- **v1 (default)** — the round-11 exercise preserved in behaviour: 21-file read
  set, the D2/D3 dual-drill packet, `reports/round-11/handoff/expected.json`.
  The default stays v1 so the filed round-11 path is not re-pointed.
- **v2** — verifies the filed round-15 surfaces without re-rendering them:
  `reports/round-15/handoff/packet-v2-05.{md,yml}` digest-pinned, the shape gate
  over the Markdown, `packet_uncertainty.py` (15 claims) and `packet_links.py`
  (50/50) over the machine twin. The pre-existing round-16 drift (the v2
  packet's manifest pins the pre-round-16 `packet_links.py`) is named in the

- **v3** — the D2/D3/D4 triple drill: the 15 v2 claim rows are carried verbatim

  twelve D4 rows enter the ledger from `reports/round-20/handoff/claims-map.md`,
  the D4 coupling edges are atomic rows with claim back-links, and the machine
  twin is judged by both harness validators against the live repo bytes. The v3
  baseline is `reports/round-20/handoff/expected.json`.

## 3. What a v3 run does, in order

1. **input-digest** — every read-set file's digest against the baseline's
   58-entry `inputs` map; drift is `E2E-DIGEST` (exit 1) before anything else.
2. **preflight** — 16 fields, non-canon marker, licensed glossary vocabulary,
   no floating version, ledger shape and floors, uncertainty grammar per row,
   the v2-subset equality control, the D4-CL08 landed-form guard.
3. **gate-scan** — the rendered Markdown packet judged in an isolated copy
   outside the repository by `tools/gates/handoff-packet-check.py` from that
   foreign working directory; the scan must equal `16/16 + 20/20 + 0`.
4. **semantics** — the machine twin judged by `packet_uncertainty.py` (zero
   findings, `--require-oq` leg) and `packet_links.py` (every link resolves).
5. **frozen-*** — packet digest, twin digest, claim-id set and glossary
   entry-id set equal the baseline's pins; `v2_subset_digest` and `alias_state`
   are pinned too.
6. **preservation** — every read-set file re-measured after the run.

`--freeze` refuses to write unless the gate is clean, both validators are
green, and the observed scan equals the declared one — the freeze is itself an
integration gate.
