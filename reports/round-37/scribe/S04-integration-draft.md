### Synthetic `--selftest` checklist

These controls are a specification, not executed tests. Implement them with synthetic in-memory inputs and temporary directory fixtures; do not use live protected paths as mutation targets.

1. Duplicate JSON key or malformed `claims.json`/`targets.json` → strict parse fails.
2. Wrong round, missing/unresolvable baseline, or resolved baseline mismatch → CO1 fails without editing the declaration.
3. Claims with duplicate axes, freshness present, an undeclared D claim, or missing freshness-pause flag → CO2 fails.
4. Target count other than 64, duplicate seat ID, duplicate `out`, or `out` escaping `reports/round-37/` → CO3 fails and names the offending row/path.
5. A declared 64-worker allocation with an observed route missing → CO4 records unknown/CNE with owner/reason, never observed zero or a silent pass.
6. One missing target omitted from `missing_dependencies` → receipt coherence fails; an absent target never becomes an empty-success result.
7. Same runner argv in two different claim rows → both Ca inventory records survive; a repeated nested argv with an explicit same-occurrence alias is reconciled once, not multiplied by Ca12/Ca14 supplements.
8. K01 inventory fixture with 25 records and one missing/duplicate ledger key → CA4 fails exact-once coverage.
9. Ca05 fixture repeating K01's C31 commands without a distinct receipt occurrence → supplemental reconciliation links it as corroboration and does not inflate the ledger; an unexplained extra Ca05 row fails CA2.
10. Ca01-style 10 nested result records against K01's 9 argv records → CA2 remains unresolved until an explicit record mapping reconciles them; silently forcing either count fails.
11. `dispositioned-mismatch` without named field/cause/class → CA3/CA6 fails; `could-not-reproduce` without owner and reason → fails; unknown cause remains `to-verify`.
12. Claim result `passed=true` with no stored shell exit status → parser preserves the filed claim result and does not fabricate an exit code.
13. Runner row marked match after executing an absolute-root runner from an unaudited archive → containment leg rejects it; `--check` alone does not satisfy isolation.
14. Runner root resolves outside the isolated copy or a receipt output resolves to the live tree → execution refused and CNR requires owner/reason.
15. r36 fixture has C/Ca/cross passed, D failed, aggregate rejected → CA6 passes only if that exact boundary remains; a fixture that changes D to passed fails.
16. Verifier N=25 with 6 IDs → below 25%; 7 IDs → meets the integer threshold. For reconciled N=33, 8 IDs → below 25%; 9 → meets. Missing Ca08 or duplicate/overlapping samples without disclosure prevents the two-verifier gate.
17. Census ID absent from queue or extra queue ID → O1 fails with both set differences; duplicate aliases for one canonical defect must preserve source references without duplicating the row.
18. `fixed-with-evidence` without non-author command/result pointer → O2 fails. Carried row missing any owner, reason, next-touch, or round-38+ route → O2 fails.
19. Candidate from round 37 inserted to make the rounds-33–36 O census equal → O1 scope check fails unless explicitly adjudicated outside the claim denominator.
20. r34 adoption 28/17/11 vs 29/18/11 smoothed into one count, or conflated with later 29→30 growth → O3 fails and requires distinct disposition.
21. A02 fallback fixture with 15 basename-only refs and no declared fallback policy → A2 reports 15 unresolved under documented resolver; fallback matches alone do not pass the rule.
