limits (honest bounds):
  - the graded run reads the packet and the peer from the LIVE tree (the adapter hardcodes
    ROOT/examples/culture-d4/packet.d4.yml); the baseline pins those bytes by copy, so a later edit to the
    live packet is caught by this baseline's pin recomputation and by the re-run receipt, not by the
    battery's digest step alone (that step compares the copy to the pin, never the copy to the live file).
  - a missing or malformed TARGET path exits 1, not 2: the peer's `--check` answers byte-identity, so
    "no such file" is reported as "differs from the deterministic projection". Fail-closed, but the
    could-not-evaluate class is reachable only through a broken live packet or a usage error. Reported,
    not fixed: no gate behavior was changed by this seat.
  - digests are integrity, not truth: exit 0 is byte-identity of a NON-CANON projection — not a design
    PASS, not a canon ruling, and not evidence that the projection's content is sound.
