# examples/culture-d4 — D4 furnace-league drill (NON-CANON)

A fourth example culture for the lane, built in round 17 through the typed
pipeline. **NON-CANON**: not canon, not a world-bible entry, not accepted by
lore-shokunin; no real-world community, language, or craft tradition is
described, cited, or approximated, and no real-language clearance, cultural
permission, rights ruling, or authenticity claim is made anywhere.

- `brief.md` — the tree-level brief and registry pointer.
- `components/01-brief.yml` … `12-provenance.yml` — the 12 authored inputs
  (landed from `reports/round-17/d4/components/`).
- `packet.d4.yml` — generated by `tools/assemble-culture-d4.py`; never
  hand-edited.
- `typed-labels.d4.yml`, `packet.d4.typed.yml` — generated by the D4 typed
  tools; never hand-edited.
- `expected-holds.json` — the committed hold set, pinned to delivered bytes.
- `ASSEMBLY.md` — integration record: commands, digests, observed verdicts,
  and the state of each pipeline step.

Reproduce from the repository root:

```sh
python3 tools/assemble-culture-d4.py          # writes packet.d4.yml
python3 tools/assemble-culture-d4.py --check  # read-only drift check
```
