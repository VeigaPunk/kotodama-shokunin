# kotodama-shokunin — 言霊

**Linguistic-cultural worldbuilding — word and world-spirit, coupled.**

A **shokunin lane** minted and trained under the
[shokunin](https://github.com/VeigaPunk/shokunin) skill. 言霊 (kotodama)
names the premise recorded in `SKILL.md`: a culture's language is not
decoration on its world; it is evidence of it.

**Wiki:** [lane overview](https://app.devin.ai/org/veigapunk/wiki/VeigaPunk/kotodama-shokunin?branch=main)

## Domain

From `PROVINCE.md` and `SKILL.md`:

- conlang design and diachronic staging
- mythic and symbolic systems
- era / period models
- costume and material-culture terminology
- naming systems

…for fictional worlds, **feeding** the world bible. This lane generates
systems and hands them off. It never records canon.

The load-bearing handoff format lives in
`corpus/knowledge/synthesis/worldbible-integration-contract.md`.

## What it refuses

| Out of province | Owner |
|---|---|
| claiming or recording canon; consistency verification | [lore / world bible](https://github.com/VeigaPunk/shokunin-world-bible) |
| real-world rights / attribution rulings | operator / art ledger |
| game mechanics | [game-dev-2d](https://github.com/VeigaPunk/shokunin-godot-2d) / [3d](https://github.com/VeigaPunk/shokunin-3d-engines) |
| general source-research method | [chousa](https://github.com/VeigaPunk/chousa-shokunin) |
| web publishing | [kake](https://github.com/VeigaPunk/kake-shokunin) |
| prompt / skill craft | [kotoba](https://github.com/VeigaPunk/kotoba-shokunin) |

Sibling repositories, the world bible, and domain source trees are
**read-only**. Contested scope → report to the integrator, never absorb.

## How a lane learns

Append-only corpus; every claim separates observation / inference /
unknown; claims that cannot be verified are marked `to-verify`. See the
fleet [README](https://github.com/VeigaPunk/shokunin#readme).
