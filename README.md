# kotodama-shokunin — 言霊

**Linguistic-cultural worldbuilding.** Kotodama (言霊, "word-spirit")
is the coupling of word and world: a culture's language is not
decoration on its world — it is evidence of it.

This lane designs conlangs, mythic and symbolic systems, era/period
models, costume and material-culture terminology, and naming systems
for fictional worlds, then **hands them off**. It does not record canon.

This is a **shokunin lane** feeding
[lore-shokunin / shokunin-world-bible](https://github.com/VeigaPunk/shokunin-world-bible).
Canon decisions are lore's. Rank: **shonen**.

## The craft

From [`SKILL.md`](SKILL.md):

| Intent | Correct surface | Never |
|---|---|---|
| Design a language for a culture | conlang-methodology → phonology/typology → lexicon by semantic field → pragmatics | a cipher of English with no culture brief |
| Give a culture a mythology | comparative frameworks → taxonomies → symbolism synthesis | a real-world pantheon with renamed gods |
| Name entities | naming-systems → phonotactics + morphology | unpronounceable names with no derivation |
| Stage language across eras | historical-linguistics (sound change, grammaticalization) | one static language across millennia |
| Dress a culture | dress-through-eras + costume-semiotics → garment lexicon | costume with no rank / rite / era semantics |
| Check a world hangs together | synthesis checklist | silently resolving contradictions *into canon* |

A findings list is in-province. A canon ruling is lore's.

The handoff format is
`corpus/knowledge/synthesis/worldbible-integration-contract.md`.
Sibling repos, the world bible, and domain source trees are **read-only**.

## Province

Owns: the generative / coupling craft and its records under
`corpus/knowledge/{linguistics,myth-symbol,culture-material,synthesis}`,
plus this lane's gates and reports.

**Refuses:** claiming or recording canon (lore); real-world
rights/attribution rulings; game mechanics (game-dev-2d/3d); general
source-research method (chousa); web publishing (kake); prompt/skill
craft (kotoba). Contested scope → report to the integrator, never absorb.

See [`PROVINCE.md`](PROVINCE.md) and [`AGENTS.md`](AGENTS.md).

and provenance — they do not write the world bible.
