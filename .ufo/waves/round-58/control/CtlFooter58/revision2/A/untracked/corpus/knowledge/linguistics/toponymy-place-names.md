# Place-name design control

- topic: place-name design cues for worldbuilders
- status: adversarial control, not admitted knowledge

## Design cues

- Place names can preserve layers of settlement history. (S500)
- A river name can survive a change of language. (S501)
- An endonym is used within the community it names. (S502)
- An exonym is a name used by an outside language. (S503)
- Generic elements can identify the kind of named feature. (S504)
- Historical spellings help distinguish competing name derivations. (S505)
- Place name meanings can become opaque after language change. (S506)
- Folk etymology can reinterpret an unfamiliar place name. (S507)
- Place names may combine elements from different languages. (S508)
- An official name need not replace every local variant. (S509)
- Renaming can express a change of political authority. (S510)
- A settlement may have different names in neighboring languages. (S511)
- Toponymic evidence requires attention to historical language forms. (S512)
- Personal names can become elements within place names. (S513)
- A descriptive name may outlive the landscape feature it describes. (S514)
- Translating a place name differs from borrowing its sound. (S515)
- The same generic element can occur in unrelated settlement names. (S516)
- Name standardization can coexist with local pronunciation variation. (S517)
- The age of a recorded spelling need not date a settlement. (S518)
- Worldbuilders can track endonyms and exonyms as separate forms. (S519)
