# Support packet for SupportD59 (claim C, round 59)

This packet holds 14 blocks. Each block is one row of evidence: the source URL,
an anchor quote from that page, the claim the row makes (teaches), and the entry sentence
that cites it (entry, with source ids removed).

Open the URL with an ordinary GET and judge one proposition per block: does the page, as it
is served now, carry the quote as body text about protective objects or marks, and does that
quote carry both the teaches sentence and the entry sentence? A quote that sits in a title,
heading, navigation block, footer or metadata carries neither.

Write one verdict line per block, for every block, with nothing else on the line: the word
VERDICT, the block label written at that block's heading, then SUPPORTED or NOT-SUPPORTED.
SUPPORTED only when all of the above holds; otherwise NOT-SUPPORTED. A missing or repeated
verdict fails the packet.
