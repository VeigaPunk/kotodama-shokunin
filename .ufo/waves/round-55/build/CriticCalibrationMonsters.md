## 2. Counterexamples against the planned entry (critic findings)

1. **The in-lane etymology is stated flat.** `corpus/knowledge/myth-symbol/divination-omen-systems.md:72` writes "*monster* (< *monstrum*, the sign that warns)". If the new entry echoes it, it inherits a single-gloss reading. Isidore XI.iii.3 itself offers a second derivation (from *monstrare*), and *moneo* means remind, advise and teach as well as warn (rows -2, -3, -4). Impacted axis: calibration. Smallest fix: use code B and the wording in bank row 3. Route the older line to a later round; it is outside claim C's lands.
2. **The in-lane griffin line is stale.** `corpus/knowledge/myth-symbol/animal-symbolism.md:109` calls Mayor's Protoceratops proposal "attractive, contested". Witton and Hing 2024 is a newer, detailed rebuttal. The entry should not copy "contested" for the origin claim: use R for origin and C for influence (bank row 2). Route the older line to a later round.
3. **Witton figure caption typo.** The page 6 caption for Figure 2 reads "4th century BCE Mesopotamia", while the page 7 text says "4th millennium BCE". Quote the text, never the caption.
4. **Britannica's own lump.** The Britannica summary box says "In Asian cultures, the dragon managed to retain its prestige". That repeats the "all Asian dragons" lump that `civilizations/vietnam.md:111` rejects. Cite only the entry body (evil in some traditions, beneficent in others), not the box generalization.
5. **The FLOOR leg can be padded with duplicate sources.** The scouts working on taniwha, griffin fossils, Nichibunken *yōkai*, Isidore, cryptozoology and the monster lexicon will likely have opened some of these same URLs. Two S-ids for one URL pass RANGE (one row per id) and inflate FLOOR's 20 distinct ids. Impacted axes: coverage (false floor) and provenance. Fix: dedupe draft rows by URL before assigning S285 and up, and merge the quotes into one row. I checked that no existing `corpus/SOURCES.md` row holds any of these nine URLs.
6. **Route wording vs the ACCESS leg.** I ran the `BYPASS` regex from `tools/check-source-access.py`. The wording "direct request returned a Cloudflare challenge (HTTP 403): challenge met, not passed; read via Wayback capture <id>" does not match. "... 7. **Restricted beings.** Te Ara says taniwha forms vary by tribal tradition. The entry should give iwi-specific taniwha only as named in that iwi's or Te Ara's public text, and should not generalize a "Māori dragon".
