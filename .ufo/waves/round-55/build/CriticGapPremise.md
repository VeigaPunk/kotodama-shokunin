### Counterexample A — false attribution in a partial owner, which the round's own rows will contradict

`divination-omen-systems.md:72` says *monster* comes from "*monstrum*, the sign that warns", and that "Cicero glosses the four omen-words in *De Div.* 1.93 as a graded set (that which warns / displays / foretells / portends)". Cicero's gloss contains no "warns". It derives *monstra* from *monstrant* ("show"); the "warns" derivation (*moneat*) belongs to Festus. I opened three pages by ordinary means on 2026-10-22:
- `https://www.thelatinlibrary.com/cicero/divinatione1.shtml`: direct, HTTP 200. The first-guessed URL `…/divinatio1.shtml` returned 404. At §93: "Quia enim ostendunt, portendunt, monstrant, praedicunt, ostenta, portenta, monstra, prodigia dicuntur."
- `https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Cicero/de_Divinatione/1*.html` (LacusCurtius, Loeb translation by Falconer): direct, HTTP 200. At §93: "Because they 'make manifest' (ostendunt), 'portend' (portendunt), 'intimate' (monstrant), 'predict' (praedicunt)".
- `https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Atext%3A1999.04.0059%3Aentry%3Dmonstrum` (Lewis and Short): direct, HTTP 200. Under *monstrum*, sense I, it quotes Paulus' epitome of Festus: "monstrum dictum velut monestrum, quod moneat aliquid futurum".

**Impact.** ScoutCiceroDivination and ScoutMonsterLexicon are opening exactly these loci. If the entry quotes Cicero correctly, the partition will hold two incompatible statements about one passage. If it copies line 72, the entry inherits a misattribution under a new S-id. This affects calibration (false provenance) and creates two competing accounts of one passage.

**Smallest correction:**
- The entry states both ancient derivations, each carried by its own opened row: Cicero has *monstra* from *monstrant*, and Festus (via Lewis and Short) has *monstrum* from *moneat*. It must not attribute "warns" to Cicero.
- Route an erratum on `divination-omen-systems.md:72` as an open records item in `corpus/lessons/round-55.md`. Claim C's lands are only the entry, `corpus/README.md` and `corpus/SOURCES.md`, so editing line 72 inside C would put a fourth path in C's lands. Note that SET would not catch that, because it compares file names, not contents (see F15).
