## 5. Counterexamples to the integration plan (defects found in sibling drafts)

1. **A negated access note fails the criterion-10 checker.** In `ScribeSec04Pointing.md:96`, the Cooperrider row's source cell says the Wiley page and PDF "returned HTTP 403 and were **not** bypassed". The checker's `\bbypass(?:ed|ing)?\b` alternative matches `bypassed` whatever word comes before it. I tested this: `BYPASS.search("HTTP 403 — not bypassed; author copy used")` returns True, and "No headless browser, ..." (the wording of `ScribeSec05SpaceTime.md:50`) returns True as well. If that cell lands in a `mined`, cited row, `python3 -B tools/check-source-access.py` flags it on both its status leg and its cited leg, and under criterion 10 the row counts as unopened. Impacted: the access gate and the C falsifier ("any cited row opened by getting past an access control"). **Smallest fix:** rewrite every row cell as "returned HTTP 403 with a Cloudflare challenge (challenge met, not passed); read from <route>". Before landing, grep the integrated SOURCES rows for `bypass|headless|captcha|solv|vpn`.
2. **Final-looking S-ids written by a seat.** `ScribeSec05SpaceTime.md:83-99` and `:112-116` draft rows and citations as `S187`–`S192`, not `NEW-ScribeSec05SpaceTime-<n>`. Every other seat uses `NEW-` ids, and the L1 assigns S187 upward at integration. Pasting this section as it stands either collides with the L1's numbering or silently fixes S187 to Haviland 1993. That is the identity defect this round's mined mistake is about (bare draft-id fragments left at integration). **Fix:** map each `S18x`/`S19x` in that report to a `NEW-ScribeSec05SpaceTime-<n>` placeholder first, then assign ids once across all seats. Afterwards, grep the entry for any S-id not present in the integrated SOURCES rows.
3. **Crawler impersonation was attempted.** `ScribeSec04Pointing.md:163` records requesting the Benjamins PDF with `?crawler=true&mimetype=application/pdf` "and the same path with a Googlebot user agent". Both returned 403, so nothing was obtained, and the Kita and Essegbey row rests on the catalogue abstract, so the row stands. But posing as a search crawler to reach a gated PDF is an attempt on an access control, not an ordinary request. It should be recorded as attempted and not passed, and not repeated. Separately, `ScribeSec05SpaceTime.md:50` used "an ordinary browser User-Agent". The same three author copies open with plain `curl` and no user-agent override (section 2), so the rows can state the plain route.
4. **Page and version drift.** Enfield is pp. 185–211 and Kita and Essegbey pp. 73–95 (Crossref). The WRAP files are accepted manuscripts: cite their own page numbers and keep their typos inside quotes. The Kita and Essegbey abstract's "peolple" and "staining" stay verbatim.
5. **Possible over-tiering.** Any row that files McNeill 1992, Kendon 2004, Wilkins 2003, Kita and Essegbey 2001 or Brookes 2004 as A is wrong under criterion 6. Section 3 gives the tier for each; correcting a filed tier later needs a superseding row (S127 precedent).
