## 5. What would make the 229 count hollow (gaps in `accept-c.py`)

`reports/round-53/accept-c.py` checks four things: the file count, that the entry exists, the README sweep's own exit code with rows and files at 229, and the cited S-ids. It does **not** catch any of the following:

1. **Draft-id leftovers, which are this round's mined mistake.** Its regex `\bS\d{3}\b` (`accept-c.py:65`) cannot see `NEW-Seat-3`, a bare `-3` or `, -3`. An entry with every citation still in draft form passes the SIDS leg as long as one real S-id appears. `tools/check-draft-ids.py` does not exist at `60f1d2a` (checked with Glob).
2. **One citation is enough.** The SIDS leg passes with `cited ≥ 1`, so sections 3–9 could be entirely unsourced.
3. **Ranges are read by their endpoints only.** In `S187–S199`, only S187 and S199 are matched; the rows in between are never checked. The model entry writes ranges (`sign-languages-manual-modality.md:7,:9`: "S071–S122"), so seats may copy the pattern.
4. **Mentioned is not the same as supporting.** An S-id named only in the head, Recheck or Scope counts as cited. `mined` and `used-by` are written by the same author in the same landing, so the script cannot tell whether the row's page carries the sentence.
5. **The entry contract is not checked.** Nothing checks the line limit (230 or fewer), the absence of H3, the eight-field head order, H2s ending Recheck then Scope, DR-GES ids, or the NON-CANON paragraph. The DR-GES prefix has 0 hits in `corpus` and `reports` at base, so it is safe to use.
6. **Restating owners is invisible to the script**, and the falsifier in `claims.json:48` is only as good as the owner list it is checked against, which misses the four owners in §0.
7. **Duplicate rows pass.** Re-registering an S001–S186 URL as a new row passes every leg (§2).

Not hollow: `sweep.py` resolves the README from its own path (`sweep.py:44-46`), and `accept-c.py` runs the copy under `--root`, so scratch-copy runs measure the scratch tree. The sweep also checks that the README row's topic equals the entry's topic and that the counts footer matches.
