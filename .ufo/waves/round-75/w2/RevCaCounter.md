## Highest-risk concrete gaps and fixes

1. **Missing COMBINED receipt validation**: `combined_receipt_path` is parsed but unused (`743-751`, `2303-2338`). In `leg_combined`, load receipt with `show(root, lands, cfg["combined_receipt_path"])`; require it exists and contains exact Ca-lands stamp, combined revision and combined tree, matching the freshly derived values. Otherwise forged/missing receipt cannot affect PASS.
2. **REPAIR sweep/fixed-surface checks are substring/exit-only**: `1546-1590`. Compare exact required line/section and parsed sweep JSON fields to the declared values, including base first=243/last=249, lands exit=0/live last=249, zero missing/ghosts and index rows. Verify each exact R2 S899/S900 lesson row. Receipts should be byte-compared against rerun output after only explicit volatile-path normalization.
3. **LEDGER accepts absent parse**: `1283-1295`, while the contract requires parse regex with capture. Reject `parse` absent/null and reject special parse tokens unless explicitly allowed by frozen wording; `count-presence` is legitimate but already has a dedicated presence parser. Ensure every pair’s observed token metadata agrees with base recomputation if ledger records it.
4. **R1 fixture “proof” is only SOURCES helper testing**: `2230-2273`. Invoke the actual APPENDONLY leg against each fixture with all other changed files absent; assert all unrelated legs unchanged/green as frozen text says; make receipts bind exact fixture commit/tree and actual complete counter output, not regexes for a substring and exit integer.
5. **RECEIPTS uses the wrong CLI contract and tool receipts are not re-derived faithfully**: `2095-2097` omits `--main <lands>`; add it. In `2148-2181`, compare each tool receipt to stdout from both base and lands reruns (with explicit volatility normalization) and require both reruns succeeded; currently `None` results do not fail and only exit status is loosely checked.
6. **NOSTUB does not inspect all correction header-field values**: `1846-1893`. Parse the defined correction row/header structure and inspect every header-field value for placeholder tokens, while requiring ID + old/new + command in that same structured row.
7. **SEPARABLE is not an exact read-set/missing-file check**: `695-703`, `1907-1971`; missing telemetry files are skipped. Derive expected path set structurally from frozen Ca section and require each exists; enumerate exact lines/receipts and fail on absent items. Enforce forbidden patterns path-wise for `corpus/knowledge/**` and `narrative-structure-frameworks*` rather than lossy clause parsing.
8. **APPENDONLY allows unconstrained additions**: `1751-1779`; `changed_files` file-level removal logic skips new files and only checks removed lines. For modified files, additions attached to arbitrary in-place edits can escape if no removed base line is outside allowed set. Compare all added/removed hunk ranges, allowing only appended hunks or exact paired REPAIR/C-owned edits, with explicit exception paths, rather than treating “no disallowed removal” as sufficient.
