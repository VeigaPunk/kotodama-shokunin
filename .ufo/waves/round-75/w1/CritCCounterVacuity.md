## Ranked predicate repairs (exact proposed wording)

1. **CITEDLINES — pin its authority.** Replace the leg with: “CITEDLINES: `tools/check-cited-lines.py` from the materialized tree, whose blob at `<lands>` is byte-identical to `git show <freeze>:tools/check-cited-lines.py`, run over the entries, exits 0, and prints `CITED-LINES: 0 finding(s)`.” (Better still, counter uses the freeze-pinned tool bytes.)
2. **SCRATCHMIRROR — execute, do not trust receipt prose.** Replace “shows `validate --file` exit 0 on a mirrored corpus carrying the frozen rows and entries” with: “the counter materializes and validates the registry and entries named by the receipt with `sources-census.sh validate --file` at grade time, requires exit 0/no E-code, and verifies the named inputs are the frozen rows and entries; receipt text alone does not pass.”
3. **COLLCHECK — execute the guard.** Replace “files and guard-proof show a planted … found … not found” with: “the counter runs the indent guard at grade time on regenerated fixtures and verifies it finds the planted 1–3-space row and does not find the 4-space row; marker prose alone does not pass.”
4. **REPOINTED — resolve the staged/lane overlap and bind claims to sources.** Replace the final clause with: “only staged campaign IDs not adopted as lane IDs (as enumerated by the frozen by-document map) are forbidden; each source id must map to the exact cited URL, and each material factual passage must be supported by a located quote in that document’s committed evidence window.” This avoids banning S885..S892 while closing id/URL-only compliance; actual factual support still needs the non-author re-open.
5. **EVIDENCE — bind the body digest and quote position.** Append: “the recorded body `sha256` must be independently matched to the fetched response recorded for that request; the quote span must begin between 25% and 75% of an excerpt window; coupling uses only the Gate quote-column span, not another quoted cell.” The independent ordinary re-open remains necessary for authenticity.
6. **REJECTS — require per-item substantive fields.** Replace “names each refused staged row and file with reason and flip” with: “for each refused staged row/file, the parsed reason and flip cells are individually non-empty and non-dash and state the concrete refusal reason and a falsifiable condition that would reverse it; global occurrences of ‘reason’/‘flip’ do not satisfy the leg.”
7. **ENTRIES — give the shape floor a source-linked minimum.** Append: “in addition to the word floor, each entry contains a non-placeholder, source-grounded discussion for each adopted row, including that row’s Gate quote or a >=20-character NFKC overlap with its evidence window; filler repetition alone does not pass.” (Overlap is only a cheap anti-vacuity check, not a substitute for substantive review.)
8. **INDEX — close ghost-row path.** Append: “every README index row in the myth-symbol section names an existing `.md` file under `corpus/knowledge` at `<lands>`, and each adopted entry has exactly one such row whose topic equals its own `- topic:` value.”

Grounding: round-74 `accept-c.py` `leg_citedlines` invokes the lands-tree checker; `leg_scratch_mirror` only inspects receipt text/order; `leg_collcheck` scans proof files; `leg_repointed` compares IDs/URLs; `_evidence_core` hashes stored window bytes and only format-checks body SHA; `leg_rejects` checks reason/flip globally; `leg_index` checks adopted topic equality but not every row's existence. Round-74 MutPredicateC F1–F9 provide executed survivor evidence for the corresponding unchanged mechanisms; F15/F16 and its batch-2 mutants show config edit and duplicate adopted index row are caught.
