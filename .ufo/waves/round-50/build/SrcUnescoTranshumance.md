- **§13 calibration** — three flags worth banking: (a) the nine-sentence description is published twice — on the element page under a `wiki-text` class (summary text) and verbatim in the 18.COM decision's "Takes note" summary; for practice claims cite the decision copy (A) and treat the element page as the record + the same text under a summary class, never as independent corroboration; (b) the 2023 decision's R.1/R.2 are the Committee's acceptance of the file's arguments, with no figures; (c) the element is on the **Representative List**, not the Urgent Safeguarding list, and the page carries no "Threatening factors" block (the Bedu element page does), so this source cannot support an "endangered pastoralism" framing.
