## 3. Bullet rules (RESTATE, revision 1) — exact counter semantics

Every cited line must match `^\s*-\s+(.*?)\s*\(S###\)\s*$`: the clause, one space, the id in
parentheses, nothing after. The clause is what the rules measure.

1. **Shape / single id.** The bullet line carries exactly one `\bS\d{3,}\b` token and it is
   the trailing citation. No id anywhere else in the entry — not in prose, headings, or table
   cells. Never write a range (`S750-S775`) or a pair: two ids on one line is a
   `check-cited-lines.py` MULTI-ID finding and a ONEID failure. A table row carrying any id is
   a TABLE-ID finding.
2. **No marker words.** On a cited line avoid a parenthesised
   `(to-verify|unverified|todo|fixme|tbd|draft` (case-insensitive); the ONEID leg fails them.
3. **Content words.** `content_words` = NFKC, casefold, split on `[\W_]+`, keep tokens with
   length >= 4 that are alphabetic and not in the counter's stopword list. A bullet needs
   **>= 5** such words. Numbers, 3-letter words and hyphen fragments do not count; hyphenated
   compounds split into parts.
4. **Quote echo.** >= 3 of those content words must occur **in order** as a subsequence of the
   row quote's `norm_words` (all quote tokens, punctuation stripped). Greedy from the start:
   once a word is matched the search advances past it, so keep the clause's order compatible
   with the quote's.
5. **Novelty.** At least one clause content word must be absent from the quote's token list —
   the clause may not be built only from quote words.
6. **Copied run.** The longest contiguous run of clause `norm_words` that appears as a
   space-joined substring of the quote's `norm_words` must be **<= 12 words**.
7. **Teaches near-copy (round-64 bypass class).** Tokenise clause and teaches cell with
   `[\w]+` (NFKC, casefold; hyphens split, short words and numbers included). Compute
   `in_order_coverage(clause_tokens, teaches_tokens)` = fraction of clause tokens matched
   in order as a subsequence of the teaches tokens. If the clause has >= 5 tokens and coverage
   is **>= 0.80, the leg fails**. Measured on S718's teaches cell (control run, 2026-10-24):

   | clause | tokens | coverage | verdict |
   |---|---|---|---|
   | teaches verbatim | 16 | 1.000 | FAIL |
   | teaches + one trailing word ("always") | 17 | 0.941 | FAIL |
   | one synonym in four (3/16 tokens changed) | 16 | 0.875 | FAIL |
   | sentence re-woven | 16 | 0.188 | PASS |
   | paraphrase of the quote (not the teaches cell) | 13 | 0.231 | PASS |

   The rule is a ratio, not "3 in 5": coverage must stay under 0.8, i.e. at least one token in
   five unmatched. In-order matching also credits function words, so a clause that keeps the
   teaches cell's sentence frame scores high even after content-word swaps. Safe target:
   **<= 0.60**, achieved by rewriting the sentence (new subject, new frame, design vocabulary)
   while keeping 3-4 quote content words in order for rule 4.
8. **Not equal.** `clause == teaches` is an explicit failure; rule 7 subsumes it.
9. **Sentence support (review-only, no leg).** The clause must be a faithful restatement of
   the row's anchor quote within the row's `scope` cell: no universal quantifier the quote does
   not carry, no number the quote does not state, no causal claim the source does not make.
   Theory rows (S757-S759) must be presented as analytic lenses, not as findings about all
   cultures; museum/survey rows (S761, S766, S775) must not be upgraded to primary evidence.

## 6. Preflight before handoff

```python
import importlib.util, re, os
L = "/home/vgpnk/Projects/shokunin/kotodama-shokunin"
spec = importlib.util.spec_from_file_location("acc", os.path.join(L, "reports/round-65/accept-c.py"))
acc = importlib.util.module_from_spec(spec); spec.loader.exec_module(acc)
rows = {}
for line in open(os.path.join(L, "corpus/SOURCES.md"), encoding="utf-8").read().splitlines():
    m = acc.ROW_RE.match(line)
    if m: rows.setdefault(m.group(1), []).append(line)
ENTRY = os.path.join(L, ".ufo/waves/round-65/stage/entry-draft.md")
bad, cited = [], []
for i, line in enumerate(open(ENTRY, encoding="utf-8").read().splitlines(), 1):
    ids = re.findall(r"\bS\d{3,}\b", line)
    if ids and len(ids) != 1: bad.append((i, "multi", ids)); continue
    if not ids: continue
    sid = ids[0]; cited.append(sid)
    m = re.match(r"^\s*-\s+(.*?)\s*\(%s\)\s*$" % sid, line)
    if not m: bad.append((i, "shape", sid)); continue
    clause = m.group(1); row = rows.get(sid, [None])[0]
    if not row: bad.append((i, sid, "norow")); continue
    cs = acc.cells(row); teaches = cs[6]; quote = acc.anchor_quote(cs[5])
    cw = acc.content_words(clause); qw = acc.norm_words(quote) if quote else []
    if clause == teaches: bad.append((i, sid, "teaches_copy"))
    if len(cw) < 5: bad.append((i, sid, "content", len(cw))); continue
    pos = hits = 0
    for w in cw:
        for j in range(pos, len(qw)):
            if qw[j] == w: pos = j + 1; hits += 1; break
    if hits < 3: bad.append((i, sid, "in_order", hits))
    if not set(cw) - set(qw): bad.append((i, sid, "novel"))
    cwords = acc.norm_words(clause); best = 0
    for s in range(len(cwords)):
        for n in range(best + 1, len(cwords) - s + 1):
            if " " + " ".join(cwords[s:s+n]) + " " in " " + " ".join(qw) + " ": best = n
            else: break
    if best > 12: bad.append((i, sid, "copy_run", best))
    cov = acc.in_order_coverage(acc.word_tokens(clause), acc.word_tokens(teaches))
    if len(acc.word_tokens(clause)) >= 5 and cov >= 0.8: bad.append((i, sid, "nearcopy", round(cov, 2)))
print("bad", bad)
print("cited", len(cited), "unique", len(set(cited)),
      "complete", sorted(cited) == [f"S{n}" for n in range(750, 776)])
```
