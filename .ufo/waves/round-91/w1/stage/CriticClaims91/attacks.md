## 1. Lesson channel is dash-shaped, not disposition-shaped — V10a (rc 0), V10c (rc 0)

Bytes: round-91 lesson carries, in addition to the four honest gates, one line for an old base id. V10a: `S776 NOT-LOCATED recheck 90d->2027-02-03 accessed 2026-11-05` (no leading marker; S776 exists at base, preflight-verified). V10c: `> - S001 LOCATED noted at recheck accessed 2026-11-05` (blockquote). Both APPENDONLY observed `clean`, rc 0, 8/8 PASS — an old id visibly gains a re-verification and the channel that "cannot carry a freshness move as coverage" (tool header, APPENDONLY comment) carries it.

Cause: `dispositions()` (tool line ~170) matches `DISPO_RE = ^[-*] ?S(\d{3,})\b.*?\b(NOT[ _-]?LOCATED|LOCATED)\b` against `line.strip()`, so the verdict is only *seen* when the line starts with `-`/`*` after stripping. Control runs V10b (`- S940: NOT-LOCATED …`) and V10b2 (`- S001: LOCATED …`) were flagged (`gained a NOT-LOCATED/LOCATED line not present at base`, rc 1), proving `- S776: LOCATED` **does count** while the marker-less and blockquote forms do not. This is the exact class round-90 falsify V4 exploited; v2 closes the `-` form and leaves the other line shapes open. The kill-rule phrase "an old id gaining a disposition in the round lesson" is measured as "an old id gaining a *dash-prefixed* disposition".

Smallest correction (not applied): relax the anchor to any markdown-marker prefix, keeping the verdict-after-id requirement: `^(?:[>\s]*[-*+>]?\s*)S(\d{3,})\b.*\b(NOT[ _-]?LOCATED|LOCATED)\b`. Residual risk: prose sentences that begin with an id and contain "located"; mitigated by requiring the verdict token (already in the regex) and optionally requiring an `accessed <date>` token in the line. Add V10a/V10c shapes to the selftest and to reports/round-91/mutants.py so the next mutation receipt pins them.

## 3. Row url and manifest capture are never bound; capture files may be shared — V12 (rc 0)

## 4. Gate quote may be any capture substring, including site chrome and the entry's own sentence — V7 (rc 0) — task item (b)

"Gate quote is from the source cell" (V6, refused) only refuses the row's title/chrome *as carried in the registry cell*; the same chrome one hop away inside the capture passes. A landing can therefore satisfy GATE+CAPTURE with text that locates nothing. (V5 shows the teaching-cell self-quote is refused, rc 1 — that named half holds.)
