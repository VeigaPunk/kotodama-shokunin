## Gate

Axes as declared: **D / depth** (the register stratum in D4, the round-17 forecast closed), **O / operability** (the three round-25 remainders), **C / coverage** (the open-question queue 100% dispositioned). Keep the readings separate: a design document is not a packet byte, a re-pin is not an edit, a disposition is not a deletion, and a runner that exists is not a receipt.

### Rule

A forecast element is delivered when the **delivered artifact** carries it, not when a design document describes it: for most of this round three D seats had written a complete, internally consistent register stratum — eight forms, machine-readable rules, an era window, a collision sweep — and none of it was on disk, so `derived_pairs=0` on the live packet was not a clean verdict but a vacuous one, and a green gate over an empty domain was evidence about the gate, not about the stratum; then the stratum landed and the same command read `derived_pairs=8`. **Both readings are true, and only a stamp tells them apart.** A frozen row that pins bytes no longer on disk is not a red verdict about the gate — it is a statement that no gate ran, so a re-pin must land as a **new generation** naming the superseded pin and its reason, never as an edit; and the new generation's green is only worth what its paired red control is worth. A pin tail is closed when the **stale row's own replayer** still refuses it and the **new row's** same replayer passes it — a new file that merely contains the right digest proves nothing. **But a re-pin taken before a later legitimate write is not a closed tail either: it is an earlier measurement, and it must be re-taken or the delta named** — which is exactly what happened here, when the D write moved six of the O rows' read-set files and turned O's green red without any O byte being wrong. A queue row is dispositioned when it has exactly one class, a named owner that resolves, and — for `carried` — a reason and a next touch round; "dispositioned" never means the row was deleted, and a ledger that drops a row is a coverage loss wearing the word "done". A runner is a deliverable: an entry point that never parses its own arguments produces a zero-byte success, which is the round-25 false-green class one level up; and a runner whose control fixture the graded gate cannot even parse reports a defect that is in the control, not in the artifact.
