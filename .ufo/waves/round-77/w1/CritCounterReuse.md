## R76 defect classes and adaptation checks

1. **ROWS over-read — confirmed, critical.** r76 `leg_rows` rejects *every* added nonblank non-row line in `corpus/SOURCES.md` as outside `row_set` (`accept-c.py:1598-1605`). The r76 base→r77-base diff contains non-row additions (including Paths/Search-log prose), as shown by `git diff 98c486... 211f952... -- corpus/SOURCES.md | grep '^+' | ... | grep -vE '^\\+\\s*\\| S[0-9]+ '`, which prints added prose; added row-line count is `3`. R77 draft lines 63-65 expressly limits ROWS to row lines and assigns required non-row sections to INDEX. Ensure adaptation counts only `| S### |` additions within frozen `row_set`; do not preserve r76's added-line rejection in ROWS.
2. **COLLCHECK URL identity — test folding, not strings.** R76's local map-to-row comparison used `urls_compatible` (r76 `accept-c.py:3621-3631`), but this helper's broad suffix/substring compatibility is not a sound canonical document identity relation; meanwhile r77 draft specifically requires normalized document URL per staged→lane map (lines 35-37, 66-67). Adaptation must use one canonical document key on both mapped and row URLs, covering carriers/views and not accepting unrelated URLs that merely share a suffix. R77 claim's narrower stated fix should be verified against implementation rather than assuming the old helper is equivalent.
3. **Uncommitted receipts — guard freeze blobs, not path existence.** R76 R1 leg reads fixtures from checkout beside the counter or `.ufo/waves/round-76/...` and later requires receipt bodies at lands (`accept-ca.py:2366-2408`, `2493-2510`). The R77 contract says every pair/fixture telemetry reference is a blob at freeze (`CLAIMS-DRAFT.md:94-96`). Require `git cat-file -e <freeze>:<path>` for every discovered path; do not accept working-tree fixtures, later-created paths, or only the two named receipts. R77 adapted Ca docstring lines 129-131 specifies this and looks directionally correct; its code still needs cross-check against all path sources.
4. **Out-of-allowlist stated_at — confirmed frozen defect.** R76 ledger contains L76-13 ANNOTATE at `corpus/knowledge/myth-symbol/narrative-structure-frameworks.md:8`, outside the r76 ANNOTATE list; the same pair is in the forbidden SEPARABLE scope. Evidence: JSON dump command over `reports/round-76/ledger.json` prints `L76-13 ANNOTATE | at: corpus/knowledge/...:8`; r76 `claims.json` ANNOTATE leg lists only LOG.md, SCORECARD.md, round-75 lesson and QUALITY.md. r76 `leg_ledger` has a conditional allowlist check but did not prevent the invalid pair from being frozen (lines 1488-1504); the delivered round-76 ledger then failed. R77 must fail ledger construction/check before freeze and enforce allowlist equality/containment without truthiness skips.
5. **Unexecutable rederive — check exact argv, including quoting, before freeze.** The r76 ledger has malformed `rederive` strings for L76-19/20/21: JSON command output shows e.g. `git grep -h -E ^window: chars= ...` with the pattern's spaces no longer one argument, while `observe_cmd` is a correctly tokenized argv. Draft explicitly requires argv-executable `observe_cmd` and re-run (lines 90-93). Check every pair by executing the exact frozen argv and verifying parsed token at base; reject malformed shell-string parsing at ledger build. Do not use a differently shlex-split/reconstructed command as evidence that the original argv executes.
6. **LEDGELIST authority:** r76 claims and counter manually repeated leg inventories, and C had INDEX twice. The r77 adapted Ca declares LEG_SPECS + `--emit-legs` + LEDGELIST, which is the right single authority, but verify generated text/digest, order, duplicate names and actual dispatch table are one-to-one. R77 draft `LEDGELIST?` is unresolved; the r77 Ca staged header says it is a leg and says 12 legs, so freeze must resolve that punctuation and emit that exact list.
