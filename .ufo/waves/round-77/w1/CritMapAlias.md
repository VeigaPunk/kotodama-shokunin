# CritMapAlias — document identity attack (round 77, W1)

## Verdict
The draft's COLLCHECK intent is right but underspecified: “normalized document URL per staged→lane map” is not an identity algorithm. A generic host+path key is unsound for query-keyed records; a generic URL-string comparison rejects legitimate aliases/captures. Freeze one canonical-key function and the alias evidence it accepts. Equality must be tuple equality, never path substring/suffix matching.

## Exact normalization rule the leg should use

Define `doc_key(url)` and use it identically for the frozen staged map and every URL extracted from the landed lane source cell:

1. Parse a complete absolute HTTP(S) URL. Lowercase scheme and DNS host; remove only the default port for that scheme. Preserve non-default ports. Do not drop `www.` generically. Reject malformed/relative URLs rather than fabricating a key.
2. If the host is `web.archive.org`, unwrap exactly a supported `/web/<14-digit timestamp><optional capture modifier>/<original absolute HTTP(S) URL>` wrapper, then restart parsing on the embedded URL. Strip the timestamp and capture modifier only. Reject malformed wrappers. Do not use substring or suffix matching to infer an original URL.
3. Drop fragment. Normalize path by removing dot-segments and a trailing slash (except root); preserve path case. Normalize percent-escape hex case and decode only RFC-unreserved octets; do not decode reserved delimiters such as `%2F` into path separators.
4. Parse query as a multiset of decoded `(name,value)` pairs, sort pairs for key construction, preserve duplicate pairs and case. Treat `+` as space only in query form decoding. Do not discard tracking-looking parameters generically.
5. For `openstd.samr.gov.cn/bzgk/std/newGbInfo` and `/bzgk/std/showGb`, apply one explicit frozen alias rule: canonical class `openstd-record`, identity is the exact `hcno` value (require exactly one nonempty hcno); ignore `type=online` only for this documented alias class. Thus showGb/newGbInfo and query-order variants match for same hcno, while different hcno values remain distinct. Any additional host/path alias needs a frozen explicit rule backed by source/redirect evidence; otherwise keys remain distinct.
6. Compare complete keys for equality. A staged ID maps to a lane row only if its frozen map record's key equals at least one URL key in that row's source cell. Enforce one staged ID→one lane ID, and reject conflicting duplicate records; keep raw URLs alongside keys for audit.

This is deliberately conservative: scheme is not part of the identity after URL parsing (HTTP/HTTPS representations of the same origin URL can match), but host and path remain significant; query is significant except for the explicit openstd alias. Do not infer identity from numeric substrings, article titles, shared path fragments, or redirect behavior not recorded in the frozen map.

## Impacted axes / smallest safe correction
- **C / COLLCHECK (and ROWS same-page live+capture predicate):** false negatives for archive/live pairs or documented aliases; false positives if query is discarded or path containment is reused. The r77 draft also needs query-aware semantics to make its named openstd example sound.
- **Smallest correction:** freeze a single query-aware `doc_key` contract plus explicit, evidence-backed host/path alias table (at minimum web.archive wrapper and the openstd hcno alias above); make COLLCHECK use exact key equality for both map URL and all lane-cell URLs. Add fixtures for different `hcno`, reordered query, `type=online`, live+Wayback, fragments, host/path case, and a substring/suffix collision. The draft's current phrase alone does not establish these behaviors.
